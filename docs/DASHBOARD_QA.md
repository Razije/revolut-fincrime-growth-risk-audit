# Dashboard QA

Browser verification on 21 September 2026 confirmed that the Streamlit app loads the configured ZIP dataset and renders the Growth Audit and Top 5 Targets tabs without visible runtime errors. The Growth view displays 78.2%, 75.3%, 71.7%, the 6,989-person denominator, the 200-user fraud-screen decrement, the 249-user repeat-use decrement, and the 6.42-point total bridge. The Top 5 view displays the exact five ranked user IDs, component-score visualisation, per-target rationale expanders, and a separate table of high amount-severity users who were not selected. The layout is legible at the standard desktop viewport and the dashboard exposes CSV download for the Top 5.
The Risk Overview tab also rendered correctly, showing 14,543 confirmed-fraud events, a 2.11% row-level fraud rate, 299 users with confirmed fraud, and 12,023 non-positive amount rows. Type-level fraud-rate and fraud-event-mix charts were visible. The browser console contained no runtime errors after navigating across the dashboard tabs.
