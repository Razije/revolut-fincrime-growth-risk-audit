# Render Deployment QA

Pre-deployment testing on 21 September 2026 confirmed that the Streamlit app starts in public deployment mode with `FINCRIME_ALLOW_UPLOAD=false`, responds successfully at `/_stcore/health`, and loads the committed audit summary and ranking without the raw transaction file. The sidebar explicitly states that the public deployment contains derived audit outputs only and that raw transaction data are not deployed. The Growth Audit tab renders the expected 78.2%, 75.3%, 71.7% and 6,989 figures, the reconciliation chart and the dataset limitations. The local service log contains no runtime exception, and all deprecated `use_container_width` arguments were replaced with the supported `width="stretch"` API.
The Risk Overview tab also renders correctly in summary-only mode, including 14,543 confirmed-fraud events, the 2.11% event rate, 299 affected users, the by-type fraud-rate chart and event-mix donut. The Top 5 tab renders the five priority users, component chart, case rationales, challenger table and CSV download. These checks confirm that the public app remains fully useful without deploying raw transaction rows.
